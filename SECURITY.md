# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/prabinpebam/focus-notes/security/advisories/new). Don't open a public issue.

Include what's affected, how to reproduce it, and the impact you expect. You'll get an acknowledgement within 7 days, and a plan or fix timeline once the report is confirmed. Reporters are credited in the advisory unless they'd rather not be.

## Scope

Focus Notes is currently a specification with no released code. Once releases exist, the latest stable release is supported. The security model, including the threat model, token handling, and the encryption of shared notes, is described in [Security and privacy](documentations/architecture/security-and-privacy.md) and [Repository and publishing](documentations/architecture/repository-and-publishing.html).

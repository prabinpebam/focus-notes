A table's layout and set column widths (D-182), in a comment on the line before it.

<!-- table: layout=bleed widths=24,40,- -->
| Task | Notes | Owner |
| ---- | ----- | ----- |
| Ship | Soon  | Me    |

<!-- table: widths=12.5,30 -->
| a | b |
|---|---|
| 1 | 2 |

A comment that isn't the line before a table stays as it is:

<!-- table: layout=bleed -->

| x |
| - |
| 1 |

Text formatting

A simple contextual toolbar that appears where you selected, plus the link editor, slash menu, and block handle.

TL;DR

Select text and a small frosted toolbar appears just above it with six controls: Turn into ▾, Bold, Italic, Strikethrough, Code, and Link. That's everything Markdown can store for a selection, and nothing more. It never covers the selection, hides as soon as you type, flips below the selection near the top of the window or on touch screens, and is fully usable from the keyboard (⌥F10 / Alt+F10). Links get an inline editor and a hover card. / opens a filtered block menu. A handle in the margin moves and converts blocks. Components IA-CMP-FORMAT, IA-CMP-LINK, IA-CMP-SLASH, and IA-CMP-HANDLE serve UC-FMT-01 to UC-FMT-05 and UC-BLOCK-01 to UC-BLOCK-03.

Contextual formatting toolbar

IA-CMP-FORMAT. Serves UC-FMT-01, UC-FMT-02, UC-FMT-04, UC-TABLE-07. The owner asked for formatting through a "simple contextual toolbar". Simple here means one row, six controls, no ⋯, and no settings.

Anatomy

Container
Frosted popover (layer 2), radius.popover, 6 px padding, 40 px tall controls, 4 px between controls, a 1 px divider after Turn into and before Link. About 500 px wide at the default UI scale.
Turn into ▾
A text button showing the current block type ("Text", "Heading 2", "Bulleted list", or "Mixed" for several types). It opens the Turn into menu below it.
Mark toggles
Bold, Italic, Strikethrough, Code. Icon buttons, 40 × 40 px, Fluent Regular icons, filled when pressed. Their tooltips include the shortcut.
Link
Icon and the word "Link", because it opens something rather than toggling. Pressed when the selection is entirely inside one link, where it opens the link editor pre-filled.

Placement

  1. Anchor

    The first line rectangle of the selection. For a selection that starts above the visible area, the first visible line.

  2. Above by default

    Centered on the anchor's horizontal middle, with its bottom 8 px above the anchor's top.

  3. Flip below

    If that would overlap the 44 px top band or the trigger, or on touch screens, it goes 8 px below the selection's last line instead.

  4. Clamp

    Kept at least 12 px inside the canvas edges. A small caret on the toolbar's edge still points at the selection when it had to slide sideways.

States and behavior

  • Pressed when the whole selection has that format. Mixed (part of the selection has it) shows a half-fill, and clicking applies the format to all of it, as Word and Google Docs do.
  • Each click is one undo step. The selection stays the same, so several formats can be applied in a row.
  • The toolbar sits above the focus-mode mask and is never dimmed.
  • Mod+U isn't in the toolbar (UNSUP-FMT-01). The first time it's pressed, a toast explains that Markdown has no underline.

Keyboard and accessibility

  • ⌥F10 / Alt+F10 moves focus into the toolbar. This is the established rich-text-editor convention, since Tab already indents lists.
  • ←/→ move between controls, Home/End jump to the ends, and Enter or Space activates. ↓ on Turn into opens its menu.
  • Esc returns focus to the text with the selection unchanged.
  • The toolbar has role="toolbar" and aria-label="Text formatting". Toggles use aria-pressed (mixed for partial). Opening it doesn't move focus or announce anything, so screen-reader users aren't interrupted mid-selection.

Link editor and hover card

IA-CMP-LINK. Serves UC-FMT-03.

MomentDesign
Create (Link button, or Mod+K with a selection)The toolbar turns into a one-line editor in the same spot: a URL field (focused, pre-filled from the clipboard if it holds a URL), [Apply] and [Cancel]. Enter applies and Esc cancels, both keeping the selection.
Paste a URL over selected textMakes a link right away (Notion, Google Docs, Slack). Mod+Z straight after pastes the URL as text instead.
Type or paste a bare URLBecomes an autolink when followed by a space or Enter.

Open a linkMod+click, or [Open] on the card. A plain click places the caret, because this is an editor. Links to other notes open in the app, and web links open in the default browser.
Link to another noteTyping in the URL field also searches note titles (the same index as Spotlight) and inserts a relative Markdown link.
Invalid addressShown inline under the field: "Use a full web address (https://…) or pick a note." The field stays open.

Slash menu

IA-CMP-SLASH. Serves UC-BLOCK-01, UC-BLOCK-02, UC-TABLE-01.

  • Opens when / is typed at the start of an empty block, or after a space. It doesn't open inside a word, so and/or stays text, and it doesn't open in code blocks or table cells.
  • Placement: a popover 8 px below the caret (above it when there's no room), 320 px wide, showing up to 8 rows before scrolling.
  • Groups: Text (Text, Heading 1–3, Quote), Lists (Bulleted, Numbered, To-do), Insert (Table, Divider, Code block). Future components (Image, Gallery) join Insert through the block registry.
  • Rows: 16 px icon, name, a one-line hint on the selected row only, and on the right the Markdown shortcut (##) or key (⌥⌘2).
  • Filtering: characters typed after / filter by name and synonyms ("h2", "title", "grid" → Table, "checkbox" → To-do). Matching letters are bold. With no match: "No blocks match ‘xyz’. Press Esc to keep the text."
  • Keyboard: ↑/↓ move, Enter or Tab inserts, and Esc closes and leaves the typed /query as text. Backspace past the / closes it.
  • Result: the current block becomes the chosen block, or a new block is inserted below if the current one has text. The caret lands inside the new block (in a table, the first header cell).

Block handle

IA-CMP-HANDLE. Serves UC-BLOCK-03. Priority P1. It uses Tiptap's MIT DragHandle extension.

  • Where: in the left gutter, 24 px outside the reading column, level with the block's first line. A six-dot grip, 20 × 24 px visible, with a 32 px hit area.
  • When: shown while the pointer is over the block (fade in 80 ms), and for the caret's block during keyboard block-selection mode. Never shown while typing. On touch screens it's shown for the focused block only.
  • Click: opens the block menu: Turn into ›, Duplicate (Mod+D), Move up or down, Copy link to block, Delete (Mod+Shift+K).
  • Drag: the block lifts at 60% opacity, and a 2 px accent drop line shows where it will land, between blocks only. Near the window's top or bottom edge the note scrolls automatically. Esc during a drag cancels it.
  • Keyboard path: block selection mode (Esc while typing) and Mod+Shift+↑/↓, so the handle is never the only way.

Theme manager

Pick a look in seconds, bring a scheme you already love, or build your own, and never end up with something unreadable.

TL;DR

People change themes at setup, when their surroundings or comfort change, and when they want the tool to feel theirs. They arrive with a named scheme, a color, a font, a theme file from another app, an accessibility need, or nothing at all. Most pick a preset, some tweak one or two things, and a few import, generate, or shuffle. The manager is a right side sheet with the real note as the live preview, built in that order: Themes (gallery), Reading (font, size, spacing, width), and Edit colors. The New ▾ menu offers From a color, Shuffle, Import, and Duplicate. Appearance is System, Light, or Dark, with one chosen light theme and one chosen dark theme. A contrast guard checks every theme. View IA-VIEW-THEME serves UC-THEME-01, UC-THEME-02, and UC-THEME-04 to UC-THEME-10.

Manual, preset, or random?

The design assumes a funnel. Most people pick a preset and maybe switch light and dark. Many adjust one or two reading settings (size, font). Some start from a color or import a scheme. Few edit individual colors or shuffle for fun. So the Themes tab opens first, Reading is one tap away, and the deep tools sit behind New ▾ and Edit colors. They're never in the way, and always reachable.

The model

Appearance
System (default, follows the OS live), Light, or Dark.
Light slot and dark slot
One chosen light theme and one chosen dark theme. System mode swaps between them. Defaults are Paper and Ink.
Theme
A named set of color tokens of one kind, light or dark (see Theming → Custom themes). A family groups a light and a dark variant (for example Solarized Light and Solarized Dark). Choosing one variant offers to fill the other slot too.
Reading settings
Font, size, line height, reading width, paragraph spacing, and focus-mode dim strength. They're separate from colors and apply to every theme, so changing theme never resets your font size.

Opening and the sheet

  • Opens from: ⋯ → Theme…, right-click or long-press the toolbar's Theme button, Settings → Appearance, Spotlight (> Theme…), and the first-run "Make it yours" step (a reduced version).
  • Sheet: frosted, 380 px wide, inset 12 px from the right edge, with radius.sheet. The canvas isn't dimmed. If the note is empty, a faint sample paragraph (heading, text, list, link, code, table) is shown in the canvas while the sheet is open, so there's something to preview on. It's removed on close and never saved.
  • Header: "Theme", a close button, and the Appearance switch (System / Light / Dark).
  • Tabs: Themes, Reading, Edit colors.
  • Footer: the contrast status for the active theme ("Text contrast 9.8:1 · AAA") and Revert, which brings back exactly what was active when the sheet opened.

Themes tab (gallery)

  • Search by name or tag ("warm", "dark", "nord"). Filter chips: All, Light, Dark, High contrast, Yours.
  • Groups: Yours (custom themes, shown first when there are any), Focus Notes (built-in), and Classic schemes (named schemes, P1).
  • Tile (158 × 86 px): the theme's canvas color, an "Aa" in its text color and font, the accent and trigger-dot colors, the name, a slot label ("Light ✓", "Dark ✓") when chosen, and a contrast badge (AA or AAA) on hover or focus. The tile's ⋯ menu offers Duplicate and edit, Export, and for custom themes Rename and Delete.
  • Choosing: click or Enter fills that tile's slot (light or dark) and applies it at once. If the appearance is showing the other kind, it switches to show the choice. Toggle back with the switch.
  • Previewing with the keyboard: moving focus through tiles with arrow keys previews each one on the real note, like VS Code's theme picker. Esc returns to the chosen theme. Hovering with a pointer doesn't preview, because the whole window flashing while you move the mouse is unpleasant.

Edit colors tab

  • Built-in themes are never edited in place. The first change makes a copy named "⟨Theme⟩ (custom)" in Yours and says so in one line at the top of the tab.
  • Simple view (default): five key colors, which are Background, Surface, Text, Muted text, and Accent. Every other token is derived from them (hover, borders, selection, find highlights, focus ring, code colors).
  • All colors (disclosure): every token, grouped as in Theming. Edited tokens get a dot and a per-token Reset.
  • A color row: swatch, name, hex value, and the contrast it's checked against ("on Background 8.2:1"). Clicking the swatch opens a picker popover with a lightness, chroma, and hue picker (OKLCH, so lightness changes look even), a hex field, and an eyedropper on the desktop.
  • The trigger dot is limited to red hues and enough saturation to stay a recognizable red dot. It's the product's signature (seed spec), so a theme can retune it but never remove it.
  • Name field at the top. Changes save as you go, and Mod+Z undoes inside the editor.

Contrast guard

Body text on the canvas4.5:1AAA at 7:1
Muted text on the canvas and surfaces4.5:1AA
Link and accent text4.5:1AA
Focus ring, control borders, and the frosted circle edge against their background3:1AA (non-text)
Trigger dot against the frosted circle3:1AA (non-text)

  • Failing pairs show inline beside the color ("Text on Background 3.1:1, needs 4.5") with Fix. Fix changes only the lightness of the edited color, by the smallest amount needed, keeping its hue.
  • Tiles and the footer show the badge. Built-in themes never fail (enforced by a test).
  • A failing custom theme can be saved, after "This theme has 2 hard-to-read pairs. Save anyway?" (UNSUP-THEME-02). It's marked "Low contrast" in the gallery.
  • Focus-mode dimmed text is deliberately excluded from the guard (see Focus mode → Accessibility).

Saving, syncing, and sharing

  • Custom themes are saved as .focus-notes/themes/<name>.json in the public repository, so they sync to every computer (UC-THEME-10). They only contain colors and font names, never personal content.
  • The chosen appearance, slots, and reading settings are per device. Turning on Sync appearance stores them in .focus-notes/settings.json instead (THM-05).
  • Export: the tile's ⋯ → Export saves a .json file or copies it.
  • Delete: a custom theme that's in use falls back to the default for that slot, and a toast offers Undo.

Keyboard and accessibility

  • Tabs use the tablist pattern. The gallery is a grid where arrow keys move in two dimensions, Enter chooses, and moving focus previews. Previews are announced ("Previewing Sepia, light, AAA").
  • Every color can be set by typing a hex value, so pointer-only pickers are never required. Contrast results are written out in text, not just colored.
  • The appearance switch is a radio group. Mod+Shift+L works while the sheet is open.
  • The sheet respects reduced transparency and reduced motion (theme changes cross-fade only when motion is allowed).

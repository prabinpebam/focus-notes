Focus Notes

A calm, Markdown-native writing app: a blank canvas, one red trigger, and a focus mode that lights up only the line you're writing.

TL;DR

Notion/Loop-style editing that saves plain Markdown to your own GitHub repository. It runs on GitHub Pages or in Electron. Notes are public or private (private ones live in a submodule repository), and public notes can be shared by link. This site turns the human-written seed spec into product, experience, architecture, and delivery documentation. It is documentation only; no code has been written yet.

Signature experience

The blank canvas and trigger

Nothing but text, plus a 10 px red dot in a frosted 30 px-radius circle at the top center that opens a minimal toolbar.

Focus mode

Only the visual row under the caret stays at full strength. Everything else is subdued.

Notion-grade editing

Blocks, slash menu, Markdown shortcuts, and real table editing, all saved as plain Markdown.

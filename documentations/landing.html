Focus Notes

A calm, Markdown-native writing app: a blank canvas, one red trigger, and a focus mode that lights up only the line you're writing.

TL;DR

Notion/Loop-style editing (built on Tiptap) that saves plain Markdown to your own GitHub repository. You write in an MIT-licensed desktop app with 20 px rounded corners and an invisible title bar. One GitHub device code signs in both the app and the computer's git. Ctrl/⌘+K opens Spotlight to find anything and act on it, and the keymap copies the apps people already use. Notes are public or private (private ones live in a submodule repository), and public notes are published on GitHub Pages. This site turns the human-written seed spec and the owner's later decisions into product, experience, architecture, and delivery documentation. It is documentation only; no code has been written yet.

Signature experience

The blank canvas and trigger

Nothing but text, plus a red dot 10 px across in a frosted circle 30 px across that opens a toolbar of at most six actions.

Focus mode

Only the visual row under the caret stays at full strength. Everything else is subdued.

Spotlight

Ctrl/⌘+K finds notes, headings, text, settings, and commands, then acts on them.

Keyboard shortcuts

Four layers, from basic to pro, borrowed from the apps people already know, on macOS, iPadOS, Windows, and Linux.

The desktop app

A 20 px rounded, frameless window whose title bar is invisible until you need it.

First run and sign-in

Seven calm steps. One GitHub device code signs in the app and the terminal's git.

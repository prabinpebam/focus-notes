Focus Notes

A calm, Markdown-native writing app: a blank canvas, one red trigger, and a focus mode that lights up only the line you're writing.

TL;DR

Notion/Loop-style editing (built on Tiptap) that saves plain Markdown to your own GitHub repository. You write in an MIT-licensed desktop app with an invisible title bar (20 px rounded on Windows and Linux, native on macOS). Sign-in goes through Git's own tools, so it covers the app and the terminal, and every user's Focus Notes lives entirely in their own GitHub account, with nothing hosted by the project. Ctrl/⌘+/ opens Spotlight to find anything and act on it, and the keymap copies the apps people already use. Notes are private by default. They can be published on the user's own GitHub Pages site, or shared with named audiences through a magic link or a passcode. Agents can help through MCP and a command-line tool, within permissions the writer grants, and there is no telemetry. People start from a Get started page on GitHub Pages that leads to the download. This site turns the human-written seed spec and the owner's later decisions into product, experience, architecture, and delivery documentation. It is documentation only; no code has been written yet.

Signature experience

The blank canvas and trigger

Nothing but text, plus a red dot 10 px across in a frosted circle 30 px across that opens a toolbar of at most six actions.

Focus mode

Only the visual row under the caret stays at full strength. Everything else is subdued.

Spotlight

Ctrl/⌘+/ finds notes, headings, text, settings, and commands, then acts on them.

Keyboard shortcuts

Four layers, from basic to pro, borrowed from the apps people already know, on macOS, iPadOS, Windows, and Linux.

The desktop app

A title bar that's invisible until you need it: 20 px corners with custom window management on Windows and Linux, a native window on macOS.

First run and sign-in

Seven calm steps. Sign in through Git's own tools, and get your own workspace created in your GitHub account.

Sharing with people

Share a private note or folder with someone by name, through a magic link or a passcode. It's published only as ciphertext and can be withdrawn at any time.

Agents and automation

A local MCP server, a command-line tool, deep links, and AGENTS.md. Agents get only the permissions you grant, and every change can be undone.

Get started

A static page on GitHub Pages: download the app, and it sets up your own workspace. A browser path follows later.

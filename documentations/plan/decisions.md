# Decisions

Every assumption and design choice these docs make beyond the literal [seed spec](../seed-specs.md), in one place, so any of them can be revisited deliberately.

> [!NOTE]
> **TL;DR.** 90 decisions. D-01 to D-44, D-56, D-57, D-73, D-78 to D-80, D-84, D-85, D-87, D-89, and D-90 are settled by the owner. D-45 to D-55, D-58 to D-72, D-74 to D-77, and D-83 are proposals (D-81, D-82, and D-88 are superseded by D-90) that stand as the plan until changed. **D-56/D-57**: a strict, layered design system, and an interface defined entirely as data, with no HTML or CSS in the app. The newest owner decisions: **D-41/D-42**: private sharing with named audiences through magic links and passcodes, in the first release. **D-43**: download first, browser second. **D-44**: agent-friendly through MCP, a command-line tool, deep links, and AGENTS.md. Key owner decisions: **D-14**: 20 px corners on Windows (and Linux) by drawing the window and rebuilding window management; macOS uses its native window. **D-16**: Spotlight is <kbd>Ctrl/⌘</kbd>+<kbd>/</kbd>, and <kbd>Ctrl/⌘</kbd>+<kbd>K</kbd> is the link key. **D-19**: support every platform possible. **D-21**: no OAuth app, no registration, and no hosting by the project. Sign-in goes through Git's own sign-in tools that the user owns (with device codes), and each user's Focus Notes is an isolated instance in their own GitHub account (**D-38**). **D-90**: the browser keeps its own notes and reads the instance's notes; only the desktop app writes to GitHub, and private notes reach the browser sealed, as a share with an audience of one. The owner accepted every remaining proposal on 2026-10-13.

# Help

Answers for writing with Focus Notes, in plain words. Pick what you want to do.

> [!NOTE]
> **TL;DR.** Help has eight sections, named by what you want to do. Something went wrong? Start with [Fix a problem](fix-a-problem.md). The articles are being written now, so some sections only list what's coming.

| Section | What it helps with |
| --- | --- |
| [Get started](get-started.md) | Install Focus Notes, connect your GitHub account, and write your first note. |
| [Write](write.md) | Format with Markdown shortcuts, use focus mode, make tables, and find anything. |
| [Organize your notes](organize.md) | Create, rename, move and delete notes and folders, and get a deleted note back. |
| [Save and back up](save-and-back-up.md) | How saving and backing up work, offline and on another computer. |
| [Private notes and sharing](private-and-sharing.md) | Keep notes private, make them public, and share one with a passcode. |
| [Fix a problem](fix-a-problem.md) | What to do when Focus Notes shows a problem, starting from its exact words. |
| [Reference](reference.md) | Keyboard shortcuts, settings, and where Focus Notes keeps your files. |
| [For developers and AI agents](developers.md) | The MCP server, the command-line tool, focus-notes:// links, and other tools. |

Still stuck? [Open an issue on GitHub](https://github.com/prabinpebam/focus-notes/issues) and say what you see. GitHub is a free website that stores files for you; this is where Focus Notes is made.

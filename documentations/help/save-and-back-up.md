# Save and back up

How saving and backing up work, offline and on another computer.

> [!NOTE]
> **TL;DR.** Focus Notes saves every note on your computer as you write. In a project on GitHub, the status in the corner says whether your notes are also backed up there. The other articles in this section are being written; until then, [open an issue on GitHub](https://github.com/prabinpebam/focus-notes/issues) if you need help.

## What the backup status says

In a project on GitHub, the status in the corner of the window tells you where your work is:

- **Backed up**: everything is on GitHub.
- **Saved on this computer**: your notes are saved here, and some aren't on GitHub yet; the backup details say how many changes are waiting. It also says this just after Focus Notes starts, until it has checked what's on GitHub, so it never says *Backed up* before it knows.
- **Backing up…**: your changes are on their way.

If a note changes only its line endings (for example after another editor opened it), it doesn't count as waiting.

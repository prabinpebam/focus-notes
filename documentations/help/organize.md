# Organize your notes

Create, rename, move and delete notes and folders, and get a deleted note back.

> [!NOTE]
> **TL;DR.** New note starts writing straight away. New note in… lets you choose a folder first. Your note's title can change without changing its file name.

## Choose where to write

Press **Ctrl+Shift+N** (**Shift+Command+N** on Mac) for **New note in…**.
Choose a Public or Private folder in this project, then **Create note**.
The current folder is already chosen. Type in the search field to filter folders.
**New folder…** creates a folder inside the chosen one without leaving the picker.
Cancel creates no note; a folder you already created stays.
In Local notes the shortcut starts a note immediately, without a picker.

**Ctrl+N** (**Command+N** on Mac) still starts a note straight away.
To make a folder from Files, use **Ctrl+Alt+N** (**Option+Command+N** on Mac).

## Change a title or file name

The first heading is the title shown in Files. A new note gets its file name
once on its first save, from that title, or a dated Untitled name if it has no
title. Editing or removing the title later leaves the file name alone.

To change the file name deliberately, open the note's menu in Files and choose
**Rename file…**. This leaves the title and words untouched and updates links
from other notes. When title and file name differ, Files shows the name in
muted text; hover the row for its full path.

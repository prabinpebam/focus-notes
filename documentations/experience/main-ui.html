Main UI and the trigger

A blank canvas with one red dot. Everything that isn't writing lives behind it.

TL;DR

The window shows only the note and the trigger: a 10 px red dot inside a frosted circle with a 30 px radius, pinned at the top center. Activating it opens a minimal, transient toolbar (Files, New note, Focus, Theme, Share, Settings). Formatting controls appear only in context. Covers UI-01 to UI-06 in the requirements.

The canvas

The canvas is the whole window. At rest it shows exactly two things: the note's text and the trigger (UI-01).

  • No persistent chrome. No sidebar, tab strip, title bar, status bar, or word count. In Electron the window is frameless, and a transparent top drag strip lets the user move it. The trigger is excluded from the drag strip so it stays clickable.
  • Reading column. Text sits in a centered column. Its width is a theme token (layout.measure, default 70 characters) so line length stays comfortable on wide screens.
  • Top clearance. The column starts below the trigger's safe zone, so the frosted ring never covers text at scroll position zero. Scrolled text passes under the ring and is blurred by it, which is why the ring is frosted rather than opaque.
  • Empty note. A new note shows one placeholder line ("Start writing, or type / for blocks") in the subdued text color. Nothing else appears.
  • Save state is never a permanent indicator. See trigger states for how unsaved or failed saves surface.

The trigger

The trigger is the app's only permanent control and the one entry point to every app-level action (UI-02, UI-03).

Dot
10 px diameter, solid red. The color is a theme token, so a theme can retune the exact red but not remove it.
Ring
30 px radius, centered on the dot. Translucent surface with backdrop-filter: blur() (the "frost"). It has a hairline edge so it stays visible on blank backgrounds in both light and dark themes.
Position
Fixed, horizontally centered, near the top of the viewport. It stays in place while the note scrolls.
Hit target
The whole ring (60 × 60 px), well above the 44 px minimum for touch targets.
Semantics
A button named "Open toolbar", with aria-expanded and aria-controls pointing at the toolbar.

The minimal toolbar

The toolbar is a small frosted panel that opens directly below the trigger. It lists app-level actions only (UI-04). Text formatting never goes here.

The trigger's own shortcut is Ctrl/Cmd+., which opens the toolbar and focuses the first action.

Behavior

  1. Open

    Click, tap, Enter or Space on the trigger, or the global shortcut. The panel fades and scales in (about 150 ms; no animation with reduced motion), and focus moves to the first action.

  2. Navigate

    Arrow keys move between actions (roving tabindex). Enter runs the focused action.

  3. Act

    An action either completes at once and closes the toolbar (New note, Focus), or replaces the toolbar with its own transient panel (Files, Theme, Share, Settings).

  4. Dismiss

    Esc, clicking outside, or running an action closes every panel and restores the caret to its exact previous position.

Design rule

Each new feature has to justify a place in the toolbar. If it fits in contextual UI, a shortcut, or an existing panel, it goes there. Six actions is the upper limit, not the starting point.

Contextual editing UI

Text-level controls show up only when they apply and fade away when they don't (UI-06). Details are on Editing.

Formatting bubble

Appears above a non-empty text selection: bold, italic, strikethrough, code, link, and turn into.

Slash menu

Typing / opens a filterable list of every registered block type.

Block handle

Appears in the left margin on hover or keyboard focus. Drag to reorder, or click for block actions.

Accessibility

  • The trigger and every toolbar action can be reached and operated with the keyboard alone, and each has a visible focus indicator (UI-05).
  • The trigger has an accessible name and announces its expanded state. Panels are labeled dialogs or toolbars, and they return focus to the editor when they close.
  • The frosted ring keeps at least 3:1 contrast against the canvas in every theme. The red dot isn't the only signal for any state.
  • All motion respects prefers-reduced-motion.
